Limitations and unavailable data

These limitations affect how this report should be read. Missing data proves neither health nor failure.

  • Module System and hardware: VRAM above 4 GB is not reported precisely by Win32_VideoController.
  • Module Events: The Security log requires elevated privileges.
  • Module Events: a query failed during collection; technical details stay in the JSON.
  • Module Startup: Shortcut (.lnk) targets and publishers are not resolved: the passive-only policy avoids COM shell automation and file inspection.
  • Module Performance: Sampling covers only about 6 seconds; it cannot establish chronic behavior.
  • Module Advanced checks: A missing signature (NotSigned) is not evidence of malware.
  • The score is a review aid, not a hardware diagnosis, a warranty or a security certification.
  • Unknown or inaccessible checks never reduce the score - and never prove health.

Privacy and next steps

Privacy

  • This audit only reads information. It does not change Windows and does not install, remove or repair anything.
  • The report can still contain private information (device names, installed software, dates). Review it before sharing.
  • The sanitized JSON is the better version if you decide to share with a reviewer or an AI assistant. Sharing is optional, nothing is sent automatically and anonymization is not perfect: review the file first. The internal JSON, if you generated it, stays on this computer.
  • Sanitization masks known sensitive fields but cannot guarantee that a computer or person can never be identified from what remains.
  • Inconclusive items need confirmation by a person before any conclusion is drawn.
  • Any fix is a separate decision: evaluate each one on its own, with a backup, before acting.

The report is generated locally. Event messages and command lines are omitted or redacted. Product, process and provider names may reveal installed software. Review the report and JSON before sharing.

Methodology and version

Tool: FIX MY PC v0.1.0 (read-only).

Possible check states: OK, Finding, Inconclusive, Unsupported, Access denied, Not collected, Error.

  • The score starts at 100 and is reduced only by substantiated findings (state 'finding' with penalty > 0).
  • Category penalties are capped at the category weight; rules in the same dedupe group count once.
  • States unknown, access_denied, unsupported, not_collected and error never reduce the score.
  • The base metric uses the same central set of checks in Simple and Full modes; Full-only findings are additional analysis without penalty.
  • Insufficient coverage yields 'Provisional score' or 'Score unavailable' - never a reassuring 100/100.
